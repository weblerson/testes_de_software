# Aula de Testes de Software com pytest

Projeto prático para demonstrar testes automatizados em Python.

## Conteúdos
- Testes com pytest
- Parametrização
- Testes de exceção
- Testes de valores limite
- Relatório HTML

## Executar os testes
python -m pytest -v

## Gerar o relatório
python -m pytest -v --html=relatorio_testes.html --self-contained-html
